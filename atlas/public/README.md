# Atlas data mirror

Generated by `atlas/site/build.py`; do not edit by hand. Same published data as https://commonworld.one (platforms.json, earn.json, snapshot.json, llms-full.txt, platforms/<id>.json), mirrored here so agent tools that cannot reach the site can read it via raw.githubusercontent.com. The site is canonical; cite Atlas URLs, not this mirror.

`api/v1/` holds the API description of https://commonworld.one/api/v1/ (index.json, openapi.json, schemas/, changelog). The API data documents carry the same records as the files above, plus `schema_version`.

The `preview` field (homepage screenshot URLs on commonworld.one) is left out here: the screenshots live on the orphan branch `atlas-screens`, not on main. Read it from the site's JSON files.

The `link_safety` field and the link safety report (https://commonworld.one/atlas/safety.json) are left out here too: they change with every daily check. Read them from the site.

The public events log of card changes is not mirrored here: read https://commonworld.one/atlas/events.json (newest first) or https://commonworld.one/atlas/events.md; its source is `atlas/data/events.jsonl` on main.

Homepage screenshots are re-captured weekly by the workflow `Atlas weekly screenshots` (`.github/workflows/screens.yml`), which opens a pull request to the `atlas-screens` branch; it is never auto-merged.

Source dates (schema_version 1.10.0): a refreshed claim in `platforms/<id>.json` may carry `source_as_of` (when the source computed the figure) and `last_settlement_seen_at` (the newest settlement event the source reported), ISO 8601 UTC or null, kept apart from `observed_at` (when the Atlas read the source).

Confirmed dates (schema_version 1.11.0): a claim in `platforms/<id>.json` may carry `confirmed_at`, the newest weekly re-check that read the same fact again and found it unchanged (ISO 8601 UTC or null; never earlier than `observed_at`, which a re-check never changes). `replications` and `preview` carry `confirmed_at` the same way.

Cards v2: money and activity claims carry `evidence_level` and `evidence_label`; where a curator opened the source and set the level by hand, the claim also carries `evidence_note`, a short reason (rules: https://github.com/commonworld-one/commonworld/blob/main/atlas/CURATION.md#curator-review-of-a-level).

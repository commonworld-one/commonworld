# Atlas data mirror

Current-only records with a separate closed.json history index. Generated by `atlas/site/build.py`; do not edit by hand. Same published data as https://commonworld.one (platforms.json, earn.json, snapshot.json, llms-full.txt, platforms/<id>.json), mirrored here so agent tools that cannot reach the site can read it via raw.githubusercontent.com. The site is canonical; cite Atlas URLs, not this mirror.

`api/v1/` holds the API description of https://commonworld.one/api/v1/ (index.json, openapi.json, schemas/, changelog). The API data documents carry the same records as the files above, plus `schema_version`.

The `preview` field (source-page screenshot URLs on commonworld.one) is left out here: the screenshots live on the pinned base branch plus reviewed main-branch capture layers. Read preview metadata from the site's JSON files.

The `link_safety` field and the link safety report (https://commonworld.one/atlas/safety.json) are left out here too: they change with every daily check. Read them from the site.

The public events log of card changes is not mirrored here: read https://commonworld.one/atlas/events.json (newest first) or https://commonworld.one/atlas/events.md; its source is `atlas/data/events.jsonl` on main.

The historical screenshot workflow (`.github/workflows/screens.yml`) is retained. This build does not activate it or authorize a new visit cadence. The saved workflow describes a manual-review capture path, not an active cadence.

Current records carry overview text, visit date, sources, revision and optional real-use trials. The preview and live safety fields are omitted in this mirror. Closed history is separate and inert. Earlier claim confirmation, first-task and Cards v2 definitions are historical source documentation, not fields in these current records.
